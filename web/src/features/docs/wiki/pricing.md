# 模型与计费

## 计价方式

本站**全部以人民币计价**，客户端里看到的金额就是实际扣费金额，没有汇率折算。

计费按 **tokens** 结算，价格表里写的是「**元 / 100 万 tokens**」，输入（input）与
输出（output）分别计价。例如某模型标 `¥1 / ¥8`，意思是：

- 输入 100 万 tokens 收 ¥1
- 输出 100 万 tokens 收 ¥8

实际用量按比例折算：一次消耗 1 万输入 tokens，就是 ¥0.01。

在 **模型广场** 里点开任意模型，可以看到它的输入价、输出价、缓存价，以及不同档位
的实际价格。每条请求的实际扣费也能在 **使用日志** 里逐条查到。

## 两个档位

|          | 免费档                     | VIP                   |
| -------- | -------------------------- | --------------------- |
| 可见模型 | 低价模型子集（见模型广场） | 全部模型              |
| 并发上限 | 1                          | 5                     |
| 额度来源 | 每日重置的免费额度         | 钱包余额              |
| 计费     | 标价 ×1.0                  | **标价 ×0.8（8 折）** |

- **免费档**每天自动获得一份额度，**当天有效、不结转**，第二天重新开始。
- **VIP** 走钱包余额，充值、兑换码或订阅都可续上，并且所有模型按标价 **8 折**计费。
- 档位由管理员调整；你自己的档位可以在 **个人资料** 页看到。

## 并发上限是什么意思

并发指**同一时刻正在进行的请求数**，不是每分钟的请求数。

- 免费档 1 并发：上一个请求结束后才能发下一个。多个请求同时发出会收到 `429`。
- VIP 5 并发：可以同时跑 5 个请求。
- 超限会被**立即拒绝**（返回 429），不会排队等待。

客户端报 429 时，等当前请求结束再发即可；需要并行跑多个任务时，可以升级到 VIP。

## 计费与日志

- **余额与充值**：见 **钱包** 页面。
- **逐条扣费明细**：见 **使用日志**，每条请求都有消耗的 tokens 与扣费金额、
  以及这次扣费走的是免费额度还是钱包余额。
- **用量趋势**：见 **数据看板**。

## 常见疑问

**为什么同一个模型，我的价格和别人不一样？**
档位不同。VIP 按标价 8 折计费，免费档按标价原价。

**本站的价格为什么比别人便宜？**
本站所有模型均为**限时限量低价折扣**，价格**每天刷新**，以模型广场当日展示的价格
为准。折扣数量有限，随时可能调整。

**价格会变吗？**
会，每天刷新一次。以 **模型广场** 里显示的价格为准，你看到的即为当前生效价。
