# 常见问题

## 401 未授权

密钥不对或没带上。

- 检查请求头是 `Authorization: Bearer sk-...`（注意 `Bearer ` 后面有个空格）。
- 检查密钥没有多余的空格或换行。
- 密钥是否被禁用或删除？到 **API 密钥** 页面确认状态。

## 429 请求过多

两种原因，看返回信息区分：

| 原因         | 表现         | 怎么办                                                                |
| ------------ | ------------ | --------------------------------------------------------------------- |
| **并发超限** | 请求立刻被拒 | 同一时刻的请求数超过档位上限（免费档 1、VIP 5）。等上一个请求结束再发 |
| **额度用尽** | 提示额度不足 | 免费额度当日用完（次日恢复），或钱包余额不足（去 **钱包** 充值）      |

## 404 模型不存在

模型名写错了，或者这个模型当前没有可用线路。

- 到 **模型广场** 复制准确的模型名——**不要凭记忆写**，模型名会随上游供给变化。
- 注意后缀：`glm-5.3` 与 `glm-5.3-flash` 是两个不同的模型。

## 400 参数错误

常见的是**输出上限设得太小**：部分 GPT 系模型要求输出上限至少 16，客户端传了更小
的值就会被上游拒绝。

- 建议省略 `max_tokens` / `max_completion_tokens`，让模型自己决定；或给 4096 这样
  的正常值。
- 其他参数错误会在返回信息里指出具体字段，照着改即可。

## 503 暂时不可用

这个模型此刻没有可用线路，**过一会儿重试通常就好了**。网关会在多个上游线路之间
自动回落，重试几次仍不行说明该模型当前确实没有容量，换个模型先用。

## 响应很慢 / 超时

- 长回答本来就需要时间；客户端超时时间太短会提前断开。
- 建议把客户端超时调到 **120 秒以上**。
- 用流式（`"stream": true`）能更早看到输出，体感也更好。

## 回答被截断

通常是输出上限太低：把你的 `max_tokens` 调大，或直接省略该参数。

## 怎么查一次请求到底发生了什么

到 **使用日志** 页面，用「请求 ID」搜索。每条记录包含：使用的模型、消耗的 tokens、
扣费金额、耗时、以及失败时的错误原因。排查问题时把这条记录提供给管理员最有效。

## 换了个客户端就连不上

绝大多数情况是 **Base URL 写错**。本站要填的是带 `/v1` 的地址（如
`https://<本站域名>/v1`），而不是控制台首页地址。有些客户端只填域名、自己拼 `/v1`，
按客户端的提示填即可。详见 **客户端配置**。

## 密钥泄露了怎么办

立刻到 **API 密钥** 页面**删除**这把密钥，再创建一把新的。删除后旧密钥立即失效。
