# 快速开始

本站是一个 **OpenAI 兼容**的大模型网关：同一个地址、同一把密钥，可以调用 OpenAI、
Anthropic、Gemini、国产模型等多家的模型。

## 三步接入

### 1. 创建 API 密钥

进入 **API 密钥** 页面，点「创建 API 密钥」。密钥只在创建时完整显示一次，请立即保存。

创建时可以：

- 选择**模型范围**与**令牌分组**：令牌分组留空即可（跟随你的账号档位）。
- 设置**额度上限**与**过期时间**：留空表示不限制。

### 2. 拿到接入地址

本站的接入地址就是**你现在访问的这个域名**，控制台的 API 密钥页面也会显示可直接
复制的地址。所有请求都走 `https://<本站域名>/v1/...`。

### 3. 发起第一次请求

```bash
curl https://<本站域名>/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的密钥" \
  -d '{
    "model": "deepseek-v4.1-flash",
    "messages": [{"role": "user", "content": "用一句话介绍你自己"}]
  }'
```

拿到回复就说明接通了。下一步可以看 **客户端配置**，把密钥填进你常用的工具。

## 支持的三条协议

同一个密钥、同一个地址，三条协议都可用：

| 协议                    | 路径                   | 典型用途                   |
| ----------------------- | ---------------------- | -------------------------- |
| OpenAI Chat Completions | `/v1/chat/completions` | 绝大多数客户端与 SDK       |
| OpenAI Responses        | `/v1/responses`        | Codex 等新一代客户端       |
| Anthropic Messages      | `/v1/messages`         | Claude Code、Anthropic SDK |

调用哪一条取决于你用的客户端，不需要额外配置——网关会把它转成上游能理解的协议。

## 支持的模型

在 **探索 → 模型广场** 里可以看到当前开放的全部模型、每个模型的价格与支持的协议。
点任意模型卡片可查看详情（价格、分组价、能力、调用示例）。

模型名会随上游供给变化，**以模型广场里的清单为准**，不要写死在代码里。
